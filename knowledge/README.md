# Knowledge base (Frontline AI)

Drop `.md` or `.txt` files here. Frontline loads them as **supplemental** docs alongside the authoritative module:

`lib/prompts/csvHospitalKnowledge.js`

Seeded starter docs:
- `csv-hospital-brand.md`
- `csv-hospital-product.md`
- `csv-hospital-faq.md`

Add, edit, or remove files anytime; the bot picks up changes within a couple of seconds (or on the next message with a forced reload). Keep content CSV Hospital–only.
