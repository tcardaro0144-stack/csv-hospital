# Knowledge base (Frontline AI)

Drop `.md` or `.txt` files here. Frontline loads them dynamically into its system prompt on each message — no manual FAQ JSON edits required.

Seeded starter docs:
- `faceless-blur-brand.md`
- `csv-hospital-product.md`
- `csv-hospital-faq.md`

Add, edit, or remove files anytime; the bot picks up changes within a couple of seconds (or on the next message with a forced reload).
